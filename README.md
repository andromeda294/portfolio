# Portfólio — Jerónimo da Costa António

Portfólio pessoal de desenvolvimento full-stack, feito com React, TypeScript e Vite.

## Atualizar conteúdo

- **Nome, apresentação, experiência, formação, email e projetos:** edite `src/data/portfolio.ts`.
- **Página inicial e navegação:** `src/App.tsx`.
- **Página do E-Converse:** `src/components/ProjectDetail.tsx`.
- **Relógio de Luanda (dia, mês e hora):** `src/components/LiveClock.tsx`.
- **Imagens dos projetos:** substitua os SVGs em `public/images/` e mantenha os nomes dos ficheiros, ou atualize os respetivos caminhos nos componentes.
- **Cores, layout e animações:** `src/index.css`, `src/App.css` e `src/components/ProjectDetail.css`.

Os logótipos da stack vêm do Simple Icons e as fontes do Google Fonts; ambos precisam de ligação à internet.

## Executar localmente

```bash
npm install
npm run dev
```

## Validar

```bash
npm run build
npm run lint
```
